# TILE GAME
## 실행 환경

- MacO

## 실행 방법

`TILE.c` 를 내려받은 폴더에서 아래 한 줄을 입력한다. 컴파일과 실행이 이어져 있다.

```bash
cd ~/Downloads && cc -Wall -Wextra -std=c11 -o tile TILE.c && ./tile
```

- **반드시 터미널(Terminal)에서 실행할 것.** Xcode 나 VS Code 의 내장 콘솔은 진짜 터미널이 아니라서 키 입력과 화면 출력이 정상 동작하지 않는다.
- Linux 에서는 `cc` 대신 `gcc` 를 써도 된다.
- 실행하면 같은 폴더에 `ranking.txt` 가 자동으로 만들어진다. 미리 준비할 파일은 없다.
