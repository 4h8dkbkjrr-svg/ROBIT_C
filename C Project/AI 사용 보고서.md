## 1. 프로젝트 개요

### 1.1. 타일 기억 게임이란?

정답 타일의 위치를 외운 뒤, 그 자리를 그대로 다시 찾아내는 터미널 기반 기억력 게임이다.

N×N 판에 정답 타일 몇 개가 3초 동안 공개됐다가 사라진다. 플레이어는 판을 보며 기억한 자리를 하나씩 뒤집고 엔터로 제출한다. 라운드가 오를수록 판이 커지고 외워야 할 타일도 늘어나, 언제까지 기억할 수 있는지를 겨루는 구조다.

게임 종료 후에는 이름을 입력해 기록을 남기며, 이 기록은 파일에 저장되어 프로그램을 다시 실행해도 유지된다.

### 1.2. 게임 규칙

타일 기억 게임의 규칙은 다음과 같다.

1. 시작 — 3×3 판에서 시작하며, 목숨은 3개다.
2. 기억 단계 — 정답 타일이 '*' 로 3초 동안 공개된 뒤 전부 숨겨진다. 이 시간 동안 누른 키는 모두 무시된다.
3. 입력 단계 — 'w/a/s/d' 로 커서를 옮기고, 스페이스로 커서 위치의 타일을 뒤집는다. 잘못 뒤집었다면 같은 자리에서 스페이스를 다시 눌러 되돌릴 수 있다.
4. 제출 — 엔터를 누르면 판정한다. 뒤집은 칸과 정답 칸이 완전히 일치해야 정답이며, 정답 칸을 하나라도 빠뜨리거나 정답이 아닌 칸을 하나라도 뒤집으면 오답이다.
5. 정답인 경우 — '라운드 × 10' 점을 얻고 다음 라운드로 넘어간다.
6. 오답인 경우 — 목숨이 하나 줄고, 라운드는 그대로 유지된 채 같은 난이도를 다시 시도한다.
7. 난이도 상승 — 판은 두 라운드마다 한 칸씩 커지며 최대 5×5까지 확장된다. 외워야 할 정답 타일 개수는 판이 커지는 라운드와 한 박자 어긋나게 늘어난다.
8. 게임 종료 — 목숨이 0이 되면 게임오버다. 이름을 입력하면 점수와 도달 라운드가 랭킹에 저장되고, 상위 5명이 표시된다. 게임 도중 'q' 를 누르면 언제든 중단할 수 있다.

## 2. AI 사용 개요

### 2.1. AI 사용 원칙

프로젝트를 시작하며 네 가지 원칙을 세웠다. 이는 AI를 쓰지 않겠다는 것이 아니라, AI를 쓰고 나서도 코드가 내 것으로 남게 하기 위한 기준이다.

1. 기본적으로 코드는 스스로 작성한다.

2. AI는 모르는 지식을 질문하는 용도로 사용하고, 코드를 전부 작성해 달라는 요청은 지양한다.

3. 다음 상황에 한정하여, AI가 개입해 코드를 수정할 수 있다.
- 현재 알고 있는 지식으로는 원하는 기능을 구현할 수 없는 경우 
- 직접 디버그해도 원인을 찾지 못하는 경우 

4. AI와 대화한 이후에는 새로 습득한 지식을 이해하려고 노력한다. 대화가 끝날 때마다, 어떤 도움을 받았는지 기록한다.

## 3. Claude 사용 기록
### 3.1. 함수별 정리

전체 27개 함수에 대해 Claude를 어떻게 사용했는지 정리했다. 표기는 다음 다섯 가지로 구분한다.

| 표기 | 의미 |
|---|---|
| 없음 | 배운 범위 안에서 직접 설계하고 작성함 |
| 디버그 및 개선 | Claude에게 코드 개선점을 질문한다. |
| 개념 질문 | 모르는 문법이나, 궁금한 점을 질문해 이해한 뒤 직접 작성함 |
| 개념 질문 + 코드 예시 제시 | Claude가 알려준 예시 코드를 보고 이해한 뒤 프로그램에 맞게 변형하여 직접 작성함 |
| Claude 직접 개입 | Claude가 코드에 직접 개입함 |

함수 순서는 함수가 처음 실행되는 순서이다.

## 5. 정리

Claude는 주로 아직 배우지 않은 터미널 제어와 UI제작에서 사용했고, 지금까지 배운 내용으로 구현할 수 없는 기능들은 Claude와 상담하며, 직접 코드에 적용 및 학습하였다. 그 외, 게임 규칙 고안, 코드 알고리즘, 작동 원리, 지금까지 배운 내용들로 구현 가능한 기능들은 전부 직접 코딩했다.
